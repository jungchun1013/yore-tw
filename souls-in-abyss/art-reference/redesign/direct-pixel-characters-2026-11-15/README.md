# 五種族人物改為直接生成像素風格 · 2026-11-15

## 為什麼

遊戲裡現在三種素材走了兩條管線，所以風格不一致：

| 素材 | 做法 | 結果 |
| --- | --- | --- |
| 戰鬥背景、世界地圖 | built-in image_gen 直接生成，prompt 指定風來之國（Eastward）式的粗像素色塊 | 色塊大、邊緣硬、色數少 |
| 17 種生物 | built-in image_gen 以 reference-02/03 為造型參考**直接生成**像素風（`direct-pixel-creatures-2026-11-13/prompt.txt`），再去背、縮到戰鬥條的 2 倍存檔 | 偽像素，但色塊、描邊、色票與背景同一家 |
| 五種族人物 | 把 reference-01 插畫**縮圖**後做 ΔE 近色合併（`pixel-set-2026-11-13`），64×96 | 仍是插畫質感，沒有像素格、有反鋸齒，站在背景前明顯比怪物軟 |

使用者 2026-11-15 的決定：怪物那種偽像素好看，就讓人物比照怪物的做法重製，不是把怪物改掉。

## 這個資料夾

- `prompt.txt`：生成用提示詞，格式比照生物那份：同一張 sheet、同一個邏輯像素大小、同色材質描邊、同一組色票、五欄一列、全部面向右、腳底同一條線。附圖請附 `style-reference.png`。
- `style-reference.png`：三段拼圖，純機械合成、沒有重畫：① reference-01 五種族原版（身份）② 生物 sheet 第二排（像素風目標）③ 森林戰鬥背景（世界）。
- `scale-card.png`：遊戲裡人物與貓頭鷹的實際比例（人類 58 單位、貓頭鷹 32 單位、同一條地平線），也看得出現在人物與生物的質感落差。
- `spec.json`：交付規格與遊戲端目前的載入位置。
- `prepare.py`：拿到 sheet 後的後處理（去背、切五欄、按比例縮放、腳底對齊、輸出 RGBA），沿用生物那次的 `cut` 作法；只做機械處理，不改畫。

## 交付規格

- 一張五欄一列的 sheet 即可（暖象牙底，無文字），每欄一個種族，順序：human、elf、dwarf、giant（美術名 orc）、undead。
- 邏輯像素大小要和生物 sheet 一樣；高度以貓頭鷹為尺：人類約 1.8 倍、精靈略高於人類、矮人約 1.4 倍、獸人約 2.1 倍、亡靈約 1.5 倍。
- 全部面向右（遊戲裡人物面向怪物）。現在 human、elf 是左向靠程式鏡像，新圖統一右向後 `FACES_LEFT` 清空。
- 同色材質描邊、PALETTE 色票、每材質三階，不要黑框、不要整體偏紫。
- 五族特徵與原版服裝保留；服裝就是預設裝備。

## 之後的接法（程式端已經有洞）

- `src/ui/hero-art.ts`：`heroArtUrl(race)` 讀 `public/sprites/hero/<race>.png`，戰鬥條、建角畫面年齡列、裝備欄都走這裡。新圖切好直接覆蓋這五個檔。
- 戰鬥條目前把 64×96 縮成 38×58 畫，新圖會改成像生物一樣以 2 倍密度逐像素畫，避免縮放把像素格弄糊。
- 建角畫面上方的種族按鈕用的是舊 16×16 頭像（`icons.ts`），不在這批裡；之後可以從新圖頭部裁。

## 不在這批

裝備分層、13–17 歲身高變化、動畫、各方向視圖。這些仍照 ART-BACKLOG 的既有條目，等本體定稿後再做。

## 2026-11-15 結果

- 使用者以 `prompt.txt` 生成 `characters-sheet.webp`（1983×793，自帶透明背景，五族全部右向）。
- `prepare.py` 直接沿用它的透明通道（去掉 alpha 1–15 的淡暈），切成五張，以人類 58 單位為基準：human 56×116、elf 58×119、dwarf 78×95、giant 82×132、undead 60×108（2 倍戰鬥條密度）。
- 已接進 Claude 的遊戲工作副本（`public/sprites/hero/`，`hero-art.ts` 清空 FACES_LEFT，`scene.ts` 改逐像素繪製）並發佈到 artifact v89；尚未寫回 repo 的 souls-in-abyss/。
- 使用者再要求人物明度 +6%、飽和度 −6%：`tone.py`（HSL 相對值，只改顏色）跑在切好的五張上，結果即遊戲現用版（artifact v91）。
- 使用者改口：問題是對比，只要提亮暗部。`shadowlift.py`：飽和 ×0.893，明度 L' = L + K(1−L)²（黑 +K、中灰 +K/4、白不動），K = 0.08 / 0.14 / 0.20 三版給使用者挑；使用者選 B（0.14）、飽和改 ×0.95，為定稿，artifact v93。`tone.py`（整體提亮）作廢留檔。
