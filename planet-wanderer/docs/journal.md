## 2026-11-08

### 第 0 輪：開新專案
- **指示**：做一款機制類似 Tiny Planet 的遊戲，渲染精緻像素風或光遇美術風，色調像風來之國／Heaven Travel／光遇／薩爾達那種低飽和通透奇幻風，比 Souls in Abyss 再亮一點；小王子是隱藏典故；之後要多星球探索拓荒、少量科幻與靈魂碎片。先做一顆有 3D art shader 的星球：小王子角色、一間屋子、一道圍欄、群聚三棵樹、池塘加小岩、石碑遺跡、瑩藍鬼火、小王子風太空艇、青藍天空。
- **行動**：新 workspace `planet-wanderer/`（three.js），低解析度 toon 著色＋法線預通道＋全解析度合成（深度描邊、折邊亮線、柔和天空、大氣暈、鬼火光）；所有指定物件；星球／生活視角、WASD／點地走路、拖曳、縮放。
- **回饋**：「雖然你做到一半，但我想請你停一下做個規劃」「我還沒看計劃呢」。→ 記入長期記憶：新專案或大功能先在對話裡給計畫，等你看過再動手。

## Codex 的修改（2026-11-09，未 commit，進行中）
我只讀 diff、跑型別檢查（通過），沒有建置或截圖，以免和 Codex 自己的測試互撞。變更分五塊：

1. **像素風改成「幻彩像素」並設為預設**：拿掉低解析度色塊那一層與混合管線，所有畫風都是全解析度幾何；「像素」只剩光影交界處一條有限寬度的 Bayer 混色帶（按鈕改名「混色格」「交界混色」）。描邊預設改為無。
2. **色盤**：天空改淡紫藍→粉白、草地改薄荷綠、土路改粉灰、陰影改淡紫；高明度中性色加上世界座標的「珍珠色」（薰衣草／薄荷／桃色）。README 註明搜尋不到可驗證的「虫羊」作品集，所以是自行詮釋。
3. **小屋屋頂**：瓦片改成等厚、交錯排列、邊緣裁齊、不再隨機歪斜，屋脊下垂與脊瓦拿掉。
4. **角色**：新增 `src/characters/surfaces.ts`（由剖面長出的平滑曲面、百褶披風），旅人全部重做：頭與身體是連續曲面，臉是深色面具加兩道發光細眼（光遇式），單片髮冠加三綹髮，披風用四根骨頭做 skinning，toon 著色器加入 skinning 支援。
5. 其他：Playwright 支援 `PW_PORT` 隔離測試埠；README 改寫。
