# 給 Codex 的生圖需求（2026-11-18）

使用者已核可的方向：
- 建築：`buildings-redraw-v3.png`（赤崁樓、神農街屋、林百貨、孔廟門庭、日式町屋、擔仔麵攤）
- 墨印素材表 `tainan-ink-print-assets.png` 裡的建築、裝飾、小滿、狐狸、六樣小吃

未核可：其他人物、神明、妖怪精靈、舊裝飾、舊小吃。

所有交付一律**透明背景**、物件之間留透明間隔、不要底紙、不要光暈、不要文字。切圖程式在 `art-source/tainan/extract_ink.py`，透明背景可以直接切。

## 一、風格嘗試：層疊紙雕

參考使用者提供的紙雕風景：雲朵、山丘、草叢各自是一層有厚度的紙，邊緣是手撕或剪下的柔和曲線，層與層之間有細縫和柔和投影，背景是暖白或淡藍藝術紙。

使用者給的描述（原文）：

> 將同一場景重新詮釋為精緻的立體多層剪紙藝術，保留主體輪廓、姿勢、關鍵物件、空間關係與視覺故事。採用真實手工紙雕技法，將山體、樹木、道路、建築、人物、水域等元素概括為不同形狀的紙片，按照前景、中景、遠景逐層裁切、疊放，形成自然清晰的空間遞進。每層紙片具有真實可見的厚度、細膩纖維紋理、精緻裁切邊緣、輕微手工瑕疵及自然起伏。紙層之間保留細微間距，產生真實柔和的接觸陰影、投射陰影與遮擋關係，突出立體浮雕感。整體如精心製作的手工紙藝裝置，具有明確的層次、真實材料質感與精巧工藝。不可表現為普通扁平插畫、數字漸變或虛假的三維渲染。剪紙場景居中呈現，主體完整、比例協調，背景使用暖白、米白或淺淡自然色藝術紙，保留適度留白，僅添加必要環境細節，避免畫面擁擠。

請用**同一組題材**做 2–3 種程度不同的版本，方便並排比較：

1. 一張關卡背景：臺南神社參道（石板路、鳥居、石燈籠、松或楓、遠景紙山與雲）。
2. 同一個建築：神農街屋，維持已核可的造型，只改材質。
3. 同一個人物：小滿，維持已核可的造型，只改材質。

版本差異建議：A 層次最淺（接近已核可的墨印版）、B 中等（看得見紙層與縫）、C 最立體（接近參考圖）。

注意遊戲是俯視、物件很小：請在每張旁邊附一個縮小到約 50 px 高的版本，確認縮小後還看得清。

## 二、神明重畫：和小滿、狐狸一致

使用者說神明風格要加強，並和兩個人物一致。請以墨印素材表裡的**小滿與狐狸**為準：

- 同樣的頭身比（大頭、短身）、同樣的大眼畫法與高光、張嘴或有表情的臉。
- 同樣的紙材處理：平塗色、細印刷顆粒、極淡的接觸陰影。
- 神明的服飾與持物保留辨識度，但不要比人物複雜太多。

六位：媽祖（冠冕、垂珠、持笏）、土地公（官帽、白鬍、元寶與拐杖）、月老（紅線、姻緣簿）、虎爺（小老虎、坐姿）、七爺（白衣高帽）、八爺（黑臉矮帽）。

神明在遊戲裡只作為場景神像或道具圖示，不當敵人。

## 三、可拆卸人偶：小滿與狐狸的分件圖

遊戲已有骨架程式（`src/render/puppet.ts`），每個零件一張透明 PNG，用關節釘在一起，之後可以做走路、待機和動圖。目前只能用整張小滿切成頭和身體兩塊測試，頸部會露出接縫，所以需要正式的分件圖。

請分別為**小滿**與**狐狸**畫一組零件：

| 零件 | 說明 |
|---|---|
| head | 臉與耳朵（狐狸含狐耳）。**下緣多畫一截脖子**，會塞在身體後面 |
| hair_back | 頭後方的頭髮，會在頭的下面 |
| hair_front | 瀏海與兩側鬢髮 |
| accessory | 頭飾（小滿的蝴蝶結與花；狐狸的花飾），單獨一件 |
| body | 軀幹與褲裙或下擺，不含袖子 |
| sleeve_back / sleeve_front | 兩隻袖子連手，**肩膀處多畫一段**，會塞在身體後面 |
| leg_back / leg_front | 兩隻腳連鞋 |
| tail | 狐狸的尾巴，根部多畫一段 |

要求：

1. 每個零件**畫完整**，被別的零件擋住的部分也要畫出來，轉動時才不會露空。
2. 所有零件同一個比例、正面略側的同一個角度，和已核可的整張圖一致。
3. 另附一張**組好的參考圖**，以及每個零件在參考圖上的位置（或直接標出關節點：脖子、肩、髖、尾根）。
4. 檔名用上表的英文名，放在 `public/art/puppets/miko/`、`public/art/puppets/fox/`。

我拿到後會寫好 `rig.json`（關節位置、上下順序、待機與走路動作），在 `?puppet=miko` 預覽，並可下載走路影格做動圖。
