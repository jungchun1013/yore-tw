# 百鬼夜市：Codex 紙藝比較版

獨立複製自 Claude 的 `worktree-yokai-night-market` 工作目錄。原工作目錄未改動；存檔改用 `yokai-night-market-paper.save.v1`。

## 開啟

`npm run dev -w yokai-night-market`

- `http://127.0.0.1:5204/?atelier`：紙藝展示，同一構圖切換 Claude 素材與 Codex 素材；同景對照可拖曳分界。
- `http://127.0.0.1:5204/`：新版遊戲。
- `http://127.0.0.1:5204/?art=claude`：複製時的 Claude 遊戲美術。

對照頁共用新展示構圖，因此「Claude 素材」代表原素材在相同場景的表現，並不是原遊戲截圖。狐狸是新增展示角色，對照位置放原版雲平，並非同角色重製。

## 本輪範圍

用內建 imagegen 生成一張透明九宮格素材集：小滿、狐狸、提燈妖怪、店鋪、小祠、鳥居、櫻樹、楓樹、石燈籠。遊戲內替換小滿、提燈妖怪、店鋪、鳥居、鳳凰木位置的楓樹與行燈位置的石燈籠；其他敵人、武器和場景保留原程式造型，改用既有 craft 紙纖維／切邊／接觸陰影處理。首關石地板也降低規律格線，改為較安靜的紙面與零散石板。樹與燈的替換是風格實驗，尚未完成台南場景植物／物件考據。

生成圖片是有紙層視覺的平面 sprite，不是可拆骨架的實體紙層。現有角色的搖擺與位移仍保留，沒有新增逐部位動畫。這是第一輪混合素材測試，不代表全遊戲已換裝。

## 美術重點

日式切繪、和紙纖維、奶油／朱紅／珊瑚／鼠尾草／靛藍配色；角色大頭短肢，紙片有厚度與接觸陰影。環境以寬鬆構圖、前中後景紙山與街道支持素材。不靠均勻黑描邊或全畫面噪點表達紙感。

素材：`public/art/paper-atlas.png`。原始生成提示存於同目錄 `prompt.txt`。執行時按九宮格擷取並依 alpha 計算邊界，保留腳底錨點與透明度；無外部圖片依賴。
