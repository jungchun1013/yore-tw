調色盤Palette

每個顏色一個字母，JSON 的 rows 就是字母排成的格子，「.」是透明。改顏色會改到整張圖用到它的格子。One letter per colour; the JSON rows are a grid of letters, with "." for transparent. Changing a colour changes every cell that uses it.

JSON：{"name":"slime","rows":["..oo..","oGGGGo"],"colors":{"o":"#343842","G":"#53695e"}}。匯入 PNG 時每個顏色自動配一個字母，最大 128×128。匯出 PNG 可選倍率。JSON: {"name":"slime","rows":["..oo..","oGGGGo"],"colors":{"o":"#343842","G":"#53695e"}}. A PNG import assigns a letter per colour, up to 128×128. PNG export takes a scale.
